# CS240_Assignment5
How it works:
When running Assembler.java, it takes my FizzBuzz code from Assignment 1, src/mips4.asm, and reads through it cleaning up empty lines & labels, outputting cleanfizzbuzz.mhc-ascii; Another reader reads through each line, dividing the code between its operation and registers while the writer copies the corresponding opcode into fizzbazz.mhc-ascii and fizzbuzz.mhc-bin files, outputted to the main file.
